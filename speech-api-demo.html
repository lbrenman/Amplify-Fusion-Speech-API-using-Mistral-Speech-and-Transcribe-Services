Notes

      

        • The API must allow CORS from this page's origin, including the x-api-key and Content-Type request headers.

        • The microphone needs https:// or http://localhost. Serve this file with python3 -m http.server 8000 and open http://localhost:8000/speech-api-demo.html.

        • A page on https:// can't call an http:// API (mixed content).
